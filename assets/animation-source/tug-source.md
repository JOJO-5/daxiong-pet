# 拔河动作来源与角色核对

`tug-mouth.png` 以原始 `original-identity.png` 和 `public/spritesheet.webp` 为图像编辑参考生成。要求保留原版黑白边牧的脸型、嘴鼻、琥珀色眼睛、白额纹、耳型、修长身体、腿长、尾巴、红色胸背带与清晰像素风格；不采用已出现形象漂移的飞盘或咬球图作为参考。

原稿为 4 列 × 2 行：右向四帧、左向四帧。嘴闭在短绳上，绳子夹在上下颚之间；四肢撑地，小幅用力、松劲，代替原先张嘴跑步的拔河效果。

制作核对：左右帧已与原始参考对照，保持黑白毛色、白额纹、长嘴鼻、红胸背和修长腿部；每方向采用统一缩放与落脚基线。身体高度会随撑地姿态变化，不应将低头弯腿误标为换体型。打包后仍需查看真实桌面录屏，检查整体比例、嘴部遮挡和长短绳连接，不以本说明代替最终视觉验收。

运行 `bash scripts/pack-tug.sh` 可重复打包：新增扩展图集第 23、24 行（从 0 开始），保留原有 23 行可见像素。每方向四帧重复到八列，脚底基线 203，最近邻采样。`tug-anchors.json` 与 `tug-anchors.rs` 记录打包后每帧短绳切口坐标，由脚本读取像素计算，供引擎逐帧连接长绳。原稿保留，不覆盖原始参考。

所有后续角色素材改动必须遵守根目录 `AGENTS.md` 的角色一致性验收要求。
