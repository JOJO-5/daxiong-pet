# 陪伴体验简化与增强

用户在2026-10-14要求按设计心理学评审落地。已交付版本为1.1.0-alpha.10，保留完整/light安装包、默认CPU、可选GPU与原有数据。

## 本轮实现

| 判断依据 | 改动 | 边界 |
| --- | --- | --- |
| 可发现性与概念模型 | 四组设置；小框负责输入、完整窗口负责记录与设置 | 不增加第三套聊天历史，保留未保存的性格草稿 |
| 渐进呈现与认知负担 | 模型用途优先、文件名进详情；高级性能/GPU/外部服务折叠；投掷为主要游戏操作 | 不删除小游戏、鼠标直接投掷或外接模型能力 |
| 执行与评价的反馈 | 持续思考；显式观察进度同步宠物；区分读文字与看画面；显示观察对象与运行方式 | 自动观察不每次弹进度气泡，保持观察和说话频率独立 |
| 控制与恢复 | 暂时安静30分钟/到本地午夜；悬停和聚焦暂停阅读；回看上一句 | 不暗中开启屏幕观察或外部发送；手动互动、专注计时照常 |
| 情感体验与信任 | 保守的情境小动作；陪伴记忆、AI偏好、个人数据集中入口 | 严肃内容不定时庆祝；文字线索不是情绪识别模型 |
| 短期屏幕上下文 | 观察回复从到达起最多保留两分钟，回看不延长截止时间 | 原有截图/OCR缓存仍按采集时间两分钟失效，聊天历史仍默认30天 |

## 动作与形象

已实际查看原始动作参考，原始11行、扩展图集和姿态校准未修改；动作选择只使用已存在的行。游戏、触摸、睡眠、专注优先，旧9行包不访问扩展行。气泡实测矩形进入原生命中范围，其他透明位置保持穿透；鼠标停在气泡上时暂停自主走动，避免狗狗自己离开阅读位置。

动作预览脚本原来仍使用奔跑末帧220ms，和原生120ms不一致。本轮改为读取atlas.rs的时长，注视行注明仅逐角度展示。这是审查工具修正，不是Windows奔跑问题的完整修复。

Windows尾巴偶发外露/跑步顿感未证实彻底解决。继续以逐帧实机证据验收；本轮不盲目重排或重画原始动作。暂不新增签到、饥饿惩罚、更多小游戏或更频繁的自动看图。
