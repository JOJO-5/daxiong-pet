# 设计心理学改进版本计划

以 `docs/DESIGN-PSYCHOLOGY-REVIEW.md` 为依据，分三个可追踪版本实施。

| 版本 | 范围 | 完成与验证条件 |
| --- | --- | --- |
| 1.0.21 | 状态按钮、防重复操作、切换反馈、喂食中断说明 | 追逐/叼回/松口不能意外重置；返回后再扔；练习奖励与普通喂食区分 |
| 1.0.22 | 可重看引导、昵称保存反馈、就地错误、记忆恢复确认、桌面玩具提示 | 错过首屏提示仍能找到玩法；保存有回应；重置前理解后果；鼠标与提示匹配 |
| 1.0.23 | 面板信息层级、关系叙事、安静陪伴、减少动态效果 | 统计可展开；不虚构经历；安静设置持久化且主动互动有回应；原有记忆兼容 |

每版独立提交源码与版本说明。最后累计版本 1.0.23 完成本地 Linux 原生回归、四平台构建与检查后，推送 tag 并发布六个安装文件及校验和。

角色视觉继续遵守 AGENTS.md。不得改写原始图集；此次交互和布局改进也需要回看真实桌面录像，核对咬住、接回、松口与再扔的连续性。
