新增“安静30分钟”和“安静到明天”，到期自动恢复；手动聊天、玩耍与专注计时提醒保留，不改变观察授权和原偶遇开关。鼠标跟随改名“看向鼠标”。游戏以投掷为主要操作，“自己拖动玩具”展开后再拿出玩具。

气泡悬停或键盘聚焦时暂停消失，移开后继续剩余阅读时间；右键/托盘“重看上一句”可回看最近回复。思考提示持续到任务结束，手动屏幕观察阶段也同步给狗狗；观察回复最多在界面和回看记忆中保留两分钟，不进入长期偏好或聊天历史。

聊天回应按保守文字线索选择小动作：严肃内容安静、问句打量、明确开心时短暂开心，其他回复轻轻歪头后待机；不再按固定间隔反复庆祝。这是文字规则，不宣称模型能准确判断情绪。原始及扩展图集像素均未修改，触摸、玩法、睡眠与专注继续优先。Windows偶发尾巴外露和奔跑顿感、模型语义答偏仍需继续复核。

自动观察仍主要读OCR文字；手动“看窗口画面”结合截图和OCR，需要2B模型及视觉组件。窗口模式下3秒内切到目标窗口并保持画面；切窗或超过2分钟会使旧观察失效。当前观察对象、处理状态和当前CPU/GPU/外部服务方式都有文字提示。

本次更新（alpha.9）：新增持久化“鼠标跟随”开关，玩法和聊天设置的“陪伴方式”均可修改。关闭后暂停转头追踪和快速晃动鼠标触发的晕倒，拖动与摸摸保持可用。聊天开始配上思考小动作，回复时歪头抬爪、长回复间隔开心动作；复用大熊现有形象，旧宠物包兼容，玩耍/触摸/睡眠/专注优先。

AI回复气泡至少显示10秒并随字数延长，普通待机/互动台词不能在阅读期间顶掉回复；手动图片理解也使用独立受保护气泡。OCR重新按稳定行基准排序，避免密集多行串联；观察提示要求依据具体内容，不凭文字数量评价“桌面乱”。自动观察继续只走OCR；手动“理解图片”同时提交截图和OCR。多栏布局、截断与小模型答偏仍有限制，提示约束不代表语义质量全面通过。

图集增加当前帧显式裁剪防护，原始素材未重画。双向叼球和全部8帧的本地原生检查通过；Windows用户报告的偶发尾巴外露、奔跑顿感尚未确认彻底解决，不将裁剪防护当作完整修复。GPU有用户老显卡运行成功反馈，未核实准确型号或测提速；默认CPU与按需加速保持。

本次更新（alpha.8）：手动观察新增读文字、准备视觉模型、理解图片和完成的进度提示；手动结果同步显示在狗狗气泡和聊天设置页，不写入聊天记录或长期偏好。当前窗口模式下，请在3秒内切到目标窗口并等候结果，切窗或超过2分钟仍会丢弃旧画面。

真实看图流程检查补齐：完整桌面回归开启内置2B视觉模型，通过原生鼠标点击“理解图片”，检查实际模型回复、处理阶段和同一结果的狗狗气泡。保留完整包与light轻量包；完整包预装2B和配套视觉组件，light看图需另下载两者。后台自动观察继续默认OCR。

此前修复（alpha.7）：Windows/macOS 自动读取系统 HTTP/HTTPS 代理，覆盖模型、加速组件下载和外接 HTTPS 服务。本地 CPU/GPU 推理继续直连。代理环境变量仍支持；PAC/WPAD 自动配置不包含在此次接入中。

新增：可选 ML Drift GPU 模式（实验性）。进入「聊天记录 → 性格与设置 → 可选 GPU 加速」，点击下载组件与兼容模型，下载后点击「试运行并启用加速」。默认仍使用原 CPU；初始化/生成失败会回退。支持取消下载、停止试运行、关闭、分别删除组件和模型。

加速组件包含按需下载的平台库（压缩约26–47MB）和独立小运行器（约0.26–0.35MB）；需要额外约963MB的0.8B INT8 LiteRT文字模型。现有GGUF不能直接复用，回答能力可能比默认2B弱。图片理解和OCR继续CPU；加速文件不进入完整/轻量安装包。硬件GPU性能、驱动兼容和2B INT4转换尚未验收，不保证更快。四平台原生CPU基础通过；Linux实际界面下载、损坏拒绝启用和CPU恢复已验证。

本次同时提供完整版与文件名含`light`的轻量版。完整版安装后离线可用；轻量版不预装聊天/视觉权重，保留CPU运行器、OCR及许可证。打开“聊天记录 → 性格与设置 → 内置模型与可选下载”，点击“下载模型”；默认2B约1.27GB，可选0.8B约0.53GB，图片理解另需约0.67GB视觉组件。下载固定版本并校验SHA-256，支持进度、停止和删除副本，不自动切换模型。两版共用用户数据，模型缓存保留在本机。

内置AI功能测试版：2B文字聊天、图片理解和原生CPU OCR随安装包提供，安装后离线可用。新增明确偏好自动记忆、编辑/撤销/删除，前台窗口/显示器/整个桌面单次观察，独立观察与主动说话频率、排除应用、安静时段及一键暂停。

聊天和屏幕理解可分别配置OpenAI风格本地/远程服务，凭据保存在系统安全存储。屏幕发送有独立许可，默认只在本机处理。屏幕图片/OCR/摘要只驻留内存，最多2分钟，切窗/暂停失效，不写聊天和长期偏好。聊天仍默认本地滚动30天，支持清空全部AI个人数据。

默认Qwen3.5 2B Q4_K_M（1,270,808,032字节）+匹配BF16 projector（671,372,416字节）+PP-OCRv5 mobile（约21.5MB），不附带Python。视觉按需加载；普通后台观察只走OCR。可选下载0.8B轻量文字模型，提供进度、停止、校验、已有权重复用和删除副本。CPU线程/上下文/输出/超时/空闲释放可调。

Windows/Linux/Intel Mac CPU需要AVX2/FMA/F16C；Mac提供ARM和Intel包，本测试版最低macOS14。Linux屏幕观察支持X11，Wayland会准确提示不支持。Mac需要用户授予屏幕录制权限；安装包未签名/公证。Windows下载安装程序，单EXE不含模型资源，不作为便携包提供。实际包大小见资产与SHA256SUMS。

这仍是预发布版。小模型会说错、图片会误读，页面提示注入的语言质量试验有失败样本；宿主不提供屏幕写偏好或执行系统命令入口。8GB/11代i5、混合DPI多屏、长期办公打扰和Mac授权截图尚未实机验收。ML Drift GPU入口为可选实验性功能，尚无真实GPU硬件性能资格；不能把框架支持表或CPU基础测试当作本项目GPU适配结果。
