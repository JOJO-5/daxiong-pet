# 大熊 v1.0.23

本版包含 v1.0.21–v1.0.23 三阶段设计心理学改进。

- 接球与飞盘按钮跟随状态变化：返回后“再扔一次”，从脚边真实位置继续；追逐与松口期间避免重置。
- 拔河直接引导操作橙色绳环；喂食明确说明会结束正在进行的游戏或练习。
- 面板与托盘提供可重看的玩法说明，包含 Mac 触控板操作和“收起面板”与结束游戏的区别。
- 昵称保存有明确反馈；错误就近说明，技术详情可展开；恢复损坏记忆前说明备份位置和重置范围，并要求确认。
- 玩具与关闭按钮更容易点中；稳定偏好移入设置，主面板突出当前状态和下一步。
- 陪伴记忆优先呈现关系阶段与真实经历，数值记录仍可展开查看；离线不掉感情、不忘已学指令。
- 新增持久化的安静陪伴：暂停主动走动、闲聊、喝水提醒与偶遇，主动玩耍、喂食和专注计时提醒照常回应；原偶遇开关保留。
- 补全 CSS 减少动态效果偏好覆盖。角色图集和原始大熊形象沿用现有素材。

安装包：Windows x64 安装版与便携版；macOS Apple Silicon 与 Intel；Linux x64 AppImage 与 Debian 包。校验和见 SHA256SUMS。
