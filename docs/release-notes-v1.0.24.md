# 大熊 v1.0.24

修复语言提示气泡的边缘裁切。

- 气泡使用完整可用宽度，长提示不再被浏览器压到半个窗口宽度；顶部、左右边框与阴影保留安全空间。
- 超长文字按当前系统字体的实际排版分页，保留全部字符、换行与标点；每页至少停留 2.6 秒，错误提示在读完前不被闲聊覆盖。
- 短提示仍贴合文字大小；连续新提示会清理旧分页计时器。
- 增加真实 Linux 桌面的气泡边界、中文/英文、多行、连续字符串与错误提示回归和录屏。

角色素材、宠物窗口尺寸与嘴部道具坐标保持原有契约。

安装包：Windows x64 安装版与便携版；macOS Apple Silicon 与 Intel；Linux x64 AppImage 与 Debian 包。校验和见 SHA256SUMS。
