# 大熊 v1.0.25

新增分区轻抚：摸头与摸肚皮。

- 不用按住鼠标，在头部或肚子停留约 1.2 秒、或缓慢来回移动即可轻抚；小圆环提示等待进度，爱心反馈接触位置。
- 摸头使用大熊原有开心动作；摸肚皮会翻身露出白肚皮，轻抚时蹬腿、摇尾巴。跟随露出的肚皮继续摸，也可摸躺着的大熊的头；移开后起身。
- 按住仍可拖动；快速划过、拿着玩具与专注期间不会误触。一次连续轻抚只记录一次陪伴，保留奖励冷却。
- 原始素材和此前 25 行动画像素保持一致，新动作独立追加；旧宠物包使用原有动作反馈，不访问新增行。
- 帮助与陪伴面板同步说明轻抚；真实桌面验证覆盖接触区域、翻身/起身、拖动打断、专注与玩具互斥，以及旧宠物包兼容。

安装包：Windows x64 安装版与便携版；macOS Apple Silicon 与 Intel；Linux x64 AppImage 与 Debian 包。校验和见 SHA256SUMS。
