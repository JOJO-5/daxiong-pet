# 大熊 v1.0.26

修正摸肚皮时不自然的躺姿。

- 从倒置躯干、正面抬头的仰躺改为自然侧躺后半翻身：头侧贴地，脖子顺接胸部，肩与髋部保持低位支撑。
- 放松前爪，用后腿小幅屈伸和尾巴摆动表达舒服；去掉多余爪形轮廓，分别核对前腿、后腿及相应关节。
- 重做侧躺、露腹、蹬腿与恢复姿态，抚摸区域和提示跟随新肚皮位置；躺着仍可摸头，移开后起身。
- 原始参考与此前 25 行动画像素保持不变，保留原有拖动、游戏和旧宠物包兼容。
- 项目准则增加身体结构和动作自然度的独立验收，不能用角色相似或测试通过替代姿态检查。

安装包：Windows x64 安装版与便携版；macOS Apple Silicon 与 Intel；Linux x64 AppImage 与 Debian 包。校验和见 SHA256SUMS。
