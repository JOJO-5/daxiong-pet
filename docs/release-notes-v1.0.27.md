# 大熊 v1.0.27

增加快速晃鼠标时的星星晕倒反应，并修复正常办公时很难遇到蝴蝶或接球邀请的问题。

- 大熊盯着鼠标时，持续快速左右晃动或画圈，会晃头、头顶转星星、侧躺缓一下，然后起身；过程约 3.5 秒，触发之间休息 15 秒。
- 普通移动、慢速画圈和一次扫过不触发；拖动、玩具、专注、睡眠和隐藏时暂停。星星跟随各阶段的头部位置，不接收鼠标；系统减少动态效果偏好下保持静态星星。
- 晃头、侧躺和起身复用已有原始大熊与校正后的动作帧，全图集保持不变；旧宠物包保留原有注视行为。

- 点击其他应用、选中文字时，偶遇等待继续累计；按住鼠标期间暂缓新事件，松开后接续原等待，不再重新等待 90–150 秒。
- 已出现的偶遇不会因点击其他地方被取消；摸狗、拖狗、玩游戏、专注、安静陪伴、隐藏和睡眠仍暂停或中断偶遇。
- 互动面板明确普通办公也能遇到小惊喜。事件频率、持续时间和自然睡眠节奏保持不变。
- 增加办公点击、长按选择、快速注视、缩放比例和互动中断回归检查，并用真实桌面鼠标持续点击验证正式运行节奏。

安装包：Windows x64 安装版与便携版；macOS Apple Silicon 与 Intel；Linux x64 AppImage 与 Debian 包。校验和见 SHA256SUMS。
