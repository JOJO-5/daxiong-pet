# alpha.9 发布验收

日期：2026-10-13。公开[tag v1.1.0-alpha.9](https://github.com/JOJO-5/daxiong-pet/releases/tag/v1.1.0-alpha.9)，应用源码 `1b9b05247be0647322e5fbbf2a956ae16f80830e`，tree `df0701f9cf74114330ce2c12943398f0005cd061`，PR [#11](https://github.com/JOJO-5/daxiong-pet/pull/11)。后续验收文档提交不改变已发布应用，原正式版及alpha.8保留。

## 用户可见变化

- AI聊天/主动观察/手动看图气泡至少10秒，随字数延长，阅读期间不被普通待机/互动台词覆盖。
- “陪伴方式”提供持久化鼠标跟随开关，聊天设置和玩法偏好都能修改；关闭后暂停注视及鼠标触发晕倒，触摸/拖动继续。
- 实际聊天开始/回复驱动原生思考、歪头抬爪与间隔开心动作；玩法、触摸、睡眠、专注优先，旧9行动作兼容，原始素材像素未改动。
- OCR以固定行基准重新排序，避免密集多行串联；观察提示要求具体可见内容。仍不是完整多栏阅读顺序，OCR1200字截断保留；自动观察仍仅OCR，手动理解图片才同时提供截图。
- 增加图集当前帧显式裁剪防护。Windows偶发尾巴外露/顿感未确认彻底解决，不标记为完整修复；GPU用户反馈已独立记录，未核实型号或提速。
