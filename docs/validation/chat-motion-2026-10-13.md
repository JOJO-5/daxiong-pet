# 鼠标跟随开关与聊天小动作

日期：2026-10-13；基于 main ede977d / alpha.8 的本地未发布修改。

## 行为

鼠标跟随开关出现在玩法的“更多：记忆与偏好 → 陪伴方式”和聊天的“性格与设置 → 陪伴方式”。默认开启，原有记忆缺少此字段时保持原先行为；写入本机陪伴记忆并原子保存，关闭后不再转头追踪鼠标或由鼠标晃动触发晕倒。触摸、拖动、玩具的鼠标操作继续可用。

聊天开始时用原版 Review 小幅思考，间隔回到 Idle；内置宠物收到回复时播放 Affection，长回复阅读期间间隔播放 HappyPat。旧9行宠物使用 Waving / Idle，不访问扩展图集。手动屏幕理解与成功领取的主动观察回复也复用回复动作。取消/清空、隐藏宠物、开始玩法/专注或按下宠物时结束原聊天动作；成功回复在气泡阅读时间内间隔播放，之后回到正常待机。玩耍、触摸、晕倒、睡眠、移动和专注优先，不因AI回复取消玩法或唤醒睡眠。

## 原始角色与动作核对

已实际查看 original-action-bases.png，对照真实原生思考与歪头抬爪截图。复用原始/已有动作，不生成、重画或替换任何图集；尺寸、地面基线、像素与嘴部坐标未改动。原生录屏中的歪头/抬爪后回到站立自然，独立确认交互与角色一致性。

## 验证

前端15项通过，TypeScript/Vite构建通过。Rust128项通过（新增开关向后兼容/保存，以及聊天动画、旧图集和玩法/睡眠/专注优先级检查）。原生GUI脚本 scripts/e2e-chat-motion.py 10项通过：真实鼠标点击开关、关后待机、开后转头、思考/回复/间隔开心与清空动作。该脚本回复事件为合成夹具，不代表语言模型推理；全部动作由真实原生引擎驱动。60fps录屏与查看过的截图：/workspace/daxiong-ai-prototype/chat-motion-2026-10-13。

另外 scripts/e2e-chat-motion-real.py 用固定内置2B CPU模型实际发送聊天并完成推理，7项通过：真实请求触发思考、实际回复触发歪头动作、宠物气泡正文与模型回复一致、聊天设置存在开关。模型事件未模拟。首轮真实模型录屏因聊天窗口覆盖宠物，仅用于事件/协议检查，不能代替已查看的独立动作视觉验收。随后把宠物放到窗口左侧重录，7项再次通过，已实际查看真实模型思考与回复的宠物/气泡截图；清楚可见的60fps录屏位于 /workspace/daxiong-ai-prototype/chat-motion-real-visible-2026-10-13。

React检查：复用独立偏好组件，两窗口各自注册并清理记忆事件，加载期间/保存失败禁用开关，使用标签内复选框保持键盘可达；动画状态与定时在Rust引擎，前端只传递实际显示的AI回复事件，未增加每帧IPC请求。
