# v1.0.25 轻抚验收

## 操作与行为

真实鼠标悬停或慢速移动 1.2 秒触发，左键按住仍执行拖动。头、腹与脚部区别判定，快速穿过清除等待进度。翻身时提示跟随露出的肚皮移动，躺姿可继续摸头，离开后播放起身序列。专注、玩具、隐藏及切换宠物中断接触，不重复累计陪伴奖励。

## 本地自动验证

- 前端测试 15 项；TypeScript 与 Vite 构建通过。
- 引擎独立测试 67 项；完整应用 Rust 测试 79 项，包含缩放下的接触与拖动及原始像素校验。
- Linux 原生轻抚专项 18 项；60 fps 录屏实际检查摸头、翻身、躺着摸头、蹬腿与起身。
- 气泡边界与长文本原生回归 25 项通过。
- 初次本地和第一次完整 CI 在拖动后的下一次触摸等待超时。CI 录像显示脚本松手后立即把鼠标瞬移至屏幕角落，同一原生采样帧把这段移动作为释放轨迹，触发了已有投掷功能。脚本现等待松手后的原生轻放动作确认，再移开鼠标；新增独立检查保证明确走轻放路径。失败录像保留，第一次失败未发布。
