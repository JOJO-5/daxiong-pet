# v1.0.26 躺姿修正验收

## 问题与修改

用户指出 v1.0.25 仰躺看着诡异。复查确认：原先正面头部与仰躺胸腹的方向不协调，四肢归属与头颈过渡不清；此前角色一致性核对没有充分覆盖身体结构，不能算动作自然度通过。

制作前实际查看原始 `original-identity.png` 与 `original-action-bases.png`，使用它们作为参考。新的所有姿态并排核对黑色垂耳、白额纹、棕眼、嘴鼻、黑白毛色、修长身体及红胸背带。对照见 `assets/animation-source/petting-identity-review.png`。侧视姿态与前视姿态的投影不同，不能要求各部位二维轮廓完全相同；必须保持同一角色和连贯身体结构。
