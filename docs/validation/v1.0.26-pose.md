# v1.0.26 躺姿修正验收

## 问题与修改

用户指出 v1.0.25 仰躺看着诡异。复查确认：原先正面头部与仰躺胸腹的方向不协调，四肢归属与头颈过渡不清；此前角色一致性核对没有充分覆盖身体结构，不能算动作自然度通过。

现改为侧躺后半翻身露腹，头侧贴地、颈部顺接胸口，胸背与髋部保持低位；两条前腿松弛，两条后腿从髋部小幅屈伸，尾巴轻摆。第一稿侧躺有额外爪形轮廓，已弃用；最终稿去掉该轮廓，核对各肢与关节连接。

制作前实际查看原始 `original-identity.png` 与 `original-action-bases.png`，使用它们作为参考。新的所有姿态并排核对黑色垂耳、白额纹、棕眼、嘴鼻、黑白毛色、修长身体及红胸背带。对照见 `assets/animation-source/petting-identity-review.png`。侧视姿态与前视姿态的投影不同，不能要求各部位二维轮廓完全相同；必须保持同一角色和连贯身体结构。

## 素材与交互

只替换扩展第 25/26 行。此前 25 行 RGBA SHA-256 仍为 `2305e8704129f5b3f54f6b63ba090c96ffd2f15e5f7855e369f2f2ab7740cd18`，原始素材未修改。翻身首尾继续逐像素复用原版站姿，蹲下过渡使用已有原始形象动作。

肚皮接触区域从原先头顶上方移到侧躺躯干下侧，躺姿头部有独立区域；旧倒置姿态的高位肚皮坐标现在不触发反馈。按下拖动、专注与玩具互斥、旧宠物包处理均保留。项目准则把身体结构、动作自然度列为独立验收项。
