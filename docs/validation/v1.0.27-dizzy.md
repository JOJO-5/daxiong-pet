# v1.0.27 快速注视晕倒验收

在大熊的注视范围内，连续快速左右晃动或画圈后，它先晃头，再头顶转星星侧躺约一秒半，随后恢复原始站姿。全过程约 3.5 秒，触发后有 15 秒冷却，按下鼠标、拖动、专注、玩具、隐藏与睡眠会中断或阻止触发。

## 身体与形象

制作前实际查看 `original-identity.png` 和 `original-action-bases.png`。晃头复用原始形象的扩展撒娇帧；倒下复用 v1.0.26 校正后的侧躺休息帧，起身复用已有过渡和原始站姿。本次所有角色图集和原始素材均未修改，未绘制新头脸或扭转身体。

星星为单独的装饰层，头部位置与姿态使用同一原生帧快照。轨道在前端用 CSS transform 动画，不增加每帧 IPC；减少动态效果偏好保留三颗静态星星。所有阶段都在原生窗口内，不挡拖动或右键。

## 触发与边界

快速转向按逻辑像素计算，屏幕缩放不改变手势强度。检测短窗口内的累计移动和绕狗狗中心的转向，普通慢速移动、慢速画圈、单次扫过不触发；快速左右晃动经过狗狗中心不会清掉已有转向。切换宠物和长时间挂起会清理状态。星星晕倒适用于内置大熊，旧宠物包保留原有注视行为。

前端只渲染状态和装饰，不做行为决策；没有新增持续 DOM 监听器或计时器。组件、类型、输入穿透和减少动态效果按 React best-practices 核对。
