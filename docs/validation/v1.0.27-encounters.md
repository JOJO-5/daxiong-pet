# v1.0.27 办公偶遇修复验收

## 问题与修复

用户反馈普通办公也一直没见过偶遇。复查发现全局鼠标左键按下被当作偶遇的强制中断，即使点击其他应用，也会反复清空 90–150 秒的累计等待。两项新增引擎回归检查在旧逻辑均失败：每三秒点击桌面无法触发事件；在其他位置长按后松开，要重新等待完整间隔。

修正后只用全局按键暂缓新事件开场，等待继续累计；点击其他应用不取消已出现的事件。宠物热区、按压、拖动、游戏、专注、隐藏、安静陪伴和睡眠仍使用原有中断条件，不新增补发队列，不缩短生产间隔。面板说明更新为普通办公也会偶尔出现。

本次没有修改图集、原始参考或动作素材，v1.0.26 的侧躺姿态保持不变。

## 验证

- 新增的两个回归检查在旧逻辑失败，修复后通过；完整 Rust 81 项、前端 15 项与 TypeScript/Vite 构建通过。
- 正式计时的原生检查使用真实鼠标在狗狗之外每约两秒按下 180 ms 再松开，要求至少 30 次点击后仍在 85–170 秒内出现事件；没有使用 e2e 加速计时。
- Linux 正式计时实机通过：持续 57 次真实桌面点击后，在 122.27 秒出现蝴蝶；保留全程录屏并实际查看触发截图，确认蝴蝶显示在桌宠附近。
- 四平台打包和完整桌面回归完成后补充；目前不能宣称最终发布验证完成。
